# Project Directory Tree – web_frontend

Below is a structured overview of the `web_frontend` project folder. Key files and directories are annotated for easy navigation and understanding.

```
web_frontend/
├── README.md                # Main project readme (usage, setup, features)
├── READMEDOC.md             # Full developer usage guide (setup, build, theme, etc.)
├── READMETREE.md            # This file: directory tree and file annotations
├── eslint.config.mjs        # ESLint config for code quality
├── package.json             # npm project config, dependencies, and scripts
├── post_process_status.lock # Build/process lock/status (autogenerated)
├── public/
│   └── assets/              # Static images for phone cards (add your *.jpg, *.png here)
├── src/
│   ├── App.css              # Global CSS, theme, and layout styles
│   ├── App.js               # Main React app component/logic
│   ├── App.test.js          # Basic React app test (Jest/RTL)
│   ├── index.css            # Entry-level CSS (fonts, body styles)
│   ├── index.js             # React app entry point (bootstraps App.js)
│   ├── logo.svg             # React logo SVG asset (demo/starter)
│   ├── setupTests.js        # Test library setup file (Jest/RTL)
│   ├── data/
│   │   └── phones.json      # List of phones (id, name, image, description)
│   └── components/
│       ├── Navbar.css       # Styles for top navigation bar
│       ├── Navbar.js        # Navbar component (app name display)
│       ├── PhoneCard.css    # Card/component styles for phone tiles
│       └── PhoneCard.js     # PhoneCard component for individual phone UI
```

**Key Annotations**

- **package.json**: Contains project dependencies, scripts (`start`, `build`, `test`), and config.
- **public/assets/**: Place all phone image files here, referenced by `phones.json`.
- **src/**: Main source code (React components, data, logic, and styles).
  - **components/**: Reusable visual components.
  - **data/phones.json**: The static list of mobile phones displayed in the catalog.
- **App.js/App.css**: Core React logic and theming.
- **index.js/index.css**: Startup and global app styles.
- **setupTests.js/App.test.js**: Support/testing for the app.
- **Navbar/PhoneCard**: Major UI building blocks used to render navigation and content cards.

For more details on how to use or extend these files, please refer to the `READMEDOC.md` or `README.md`.
